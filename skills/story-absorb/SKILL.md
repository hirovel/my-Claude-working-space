把一份新的写作方法论（课程、书、访谈、讲稿）吸收进体系，而不让体系变胖。这是体系的免疫系统：营养进来，教条挡在门外。

## 过程

1. **精读**。作者给出材料或指路，通读原文（不是二手转述），写成精读笔记 `docs/sources/<大师名-作品>.md`：核心方法、适用边界、与既有体系重合和冲突的地方。
2. **蒸馏**。从笔记里挑出**真正新的**东西：可复用的概念蒸馏成锚点词（像"承诺"之于桑德森），防失误的做法蒸馏成一句纪律。题材模板、平台经验、成功学默认不取。
3. **安置**，从最便宜的层级开始向上，够用就停：
   - 只是知识 → 留在精读笔记里，零负载；
   - 新概念全体系要用 → `CONTEXT.md` 术语表加一条；
   - 强化某个既有 skill → 在那个 skill 里加改一两行；
   - 确实解决一个实测过的新失灵点 → 才值得新 reference 文件或新 skill。
4. **冲突即光谱**。新方法与既有纪律矛盾时（比如某位大师反对大纲），把它变成光谱上的一个位置或档案里的一个选项，交给作者选，不做非此即彼的裁决。

## 完成

精读笔记落盘；每条蒸馏出的东西都有明确去处或明确不取的理由；改动后的每个 skill 仍能一口气读完——说不出"这行防什么失误"的新增，删掉。
