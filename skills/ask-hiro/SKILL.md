# 路标

向作者说明这套 skills 怎么配合写小说。原则只有一条：**一切为方便写小说**——流程感能省则省，杂务（记账、归档、存档、清理）由 agent 静默处理。

约定：**目录即作品**——在哪个作品目录开会话，就写哪部作品，`story-profile.md` 是作品标记。

## 主流程

- **`/setup-story-skills`** —— 配置一部新作品：目录、git/纯本地、工作偏好默认值。纯机械设置，五分钟，每部作品一次。
- **`/brew`** —— 酝酿：和作者把想法聊成故事的盘问访谈，边聊边沉淀进档案、圣经、账本、大纲或碎片堆，并随时校准档案里的光谱与执笔模式。想聊就来，可以反复来。
- **`/draft`** —— 起草：日常写作主循环。开工自动恢复记忆，收尾自动收工。作者只管写。
- **`/absorb`** —— 把一套新的写作方法吸收进体系（精读→蒸馏→最便宜层级安置），教条挡在门外。

## 自动纪律（作者不需要记得）

- **wrap（收工）** —— 每次会话收尾自动跑：收割→交接→存档；护栏 hook 在忘收工时兜底提醒。
- **harvest（收割）** —— 从新正文提取设定入圣经、承诺入账本，冲突即报告。

## 词汇层（在其他 skill 之下运行）

- **promises** —— 承诺方法：承诺·推进·兑现，账本格式的唯一出处。
- **characters** —— 人物方法：欲望·恐惧·三滑尺·语言习惯，人物档案格式的唯一出处。

词的问题（"什么算承诺""滑尺是什么"）找它们；流程的问题找上面的入口。

## 材料放在哪

正文在 `manuscript/`（一章一文件）；设定在 `bible/`（正文的索引，每条带出处章节）；未兑现的承诺在 `ledger/promises.md`（一眼读完）；灵感随手丢 `notes/inbox.md`；删掉的场景在 `cut/`（永不真删）。选了 git 的作品：每天的稿子都有存档，说"回到某天"即可，无需懂 git。
