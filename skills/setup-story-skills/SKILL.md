配置一部新作品的工作目录。只做配置，不碰创作——故事本身是什么、想给读者什么，都留给 `/brew` 去聊。

约定：**目录即作品**——在哪个目录开会话就写哪部作品，`story-profile.md` 是作品标记。

## 设置

顺着聊，问清三件事就够（不固定轮数，作者说"都听你的"就用推荐值）：

1. **作品名与位置**。
2. **存稿方式**，推荐 git：
   - **git 管理**：每次写作自动存档，可随时"回到上周三的版本"；误删、改崩、大修反悔都能救回；可推送私有仓库做云端备份。全部由 agent 静默处理，你不需要学任何 git，唯一痕迹是一个隐藏的 `.git` 文件夹。
   - **纯本地**：目录里只有你的文件，最简单。代价是没有历史，误删改坏无法回退，备份靠自己。适合先试试或已有网盘同步习惯的作者。随时可无损转为 git。
3. **工作偏好**（作者已有明确想法就记录，没有就写默认值并标注"未校准——/brew 时会边聊边校准"）：三维度光谱（情节/人物/世界观各自偏发现式还是大纲式，默认发现式）、执笔模式（AI 主笔/共笔/作者主笔，默认 AI 主笔）。

## 落盘

只建现在就有内容的东西，目录跟着内容长：

```
<作品名>/
├── story-profile.md   # 作品档案：只放工作偏好与配置，不放故事内容
├── manuscript/        # 空目录，等第一章
└── notes/inbox.md     # 收件箱，附一行：灵感随手丢这里，格式不限
```

圣经和账本不预建——第一条承诺在 `/brew` 里诞生，圣经由收割生长。

选了 git：静默 `git init` + 首次提交（"开坑"）；把本 skill `assets/` 下的两个护栏文件复制进作品目录（`.claude/hooks/check-wrap.sh` 记得 `chmod +x`，`.claude/settings.json`）。此后一切 git 操作不出现在与作者的对话里。

## 完成

档案落盘、目录与护栏就位（git 模式已首次提交）。

- 心里已经有了，直接开写 → `/draft`
