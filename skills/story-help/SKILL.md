# 路标

向作者说明这套 skills 怎么配合写小说。全部围绕一个原则：**一切为方便写小说**，流程感能省则省，杂务（记账、归档、存档、清理）全部由 agent 静默处理。

约定：**目录即作品**——在哪个作品目录开会话，就写哪部作品。

## 三个入口

- **`/setup-story`** —— 开一部新作品。一次访谈：故事是什么、三维度光谱（情节/人物/世界观各自偏发现式还是大纲式）、执笔模式（AI 主笔/共笔/作者主笔）、存稿用 git 还是纯本地。每部作品只跑一次。
- **`/story-develop`** —— 发展想法，不写正文。大纲式维度走盘问（成果进圣经和大纲），发现式维度只攒碎片。写正文前想聊聊，或者写作中想停下来理思路，都来这里。
- **`/story-write`** —— 写正文，日常主循环。开工自动恢复记忆（交接+账本+上章结尾），收尾自动收割、记账、存档。作者只管写。

**收割**（story-harvest）不需要作者记得——每章写完自动运行，护栏 hook 会兜底提醒；想手动触发就说"收割"。

遇到新的写作方法论想纳入体系（课程、书、访谈）→ **`/story-absorb`**：精读、蒸馏、安置在最便宜的层级，教条挡在门外。

## 词汇层（在其他 skill 之下运行）

- **story-promises** —— 承诺方法：承诺·推进·兑现，账本格式的唯一出处。
- **story-character** —— 人物方法：欲望·恐惧·三滑尺·语言习惯，人物档案格式的唯一出处。

词的问题（"什么算承诺""滑尺是什么"）直接找它们；流程的问题找上面三个入口。

## 材料放在哪（作者只需要知道这些）

- 正文在 `manuscript/`，一章一个文件。
- 设定在 `bible/`，是正文的索引，每条注明出处章节；查设定先看这里。
- 未兑现的承诺（悬念、伏笔、誓言）在 `ledger/promises.md`，一眼能读完。
- 灵感随手丢 `notes/inbox.md`，agent 会定期清空归位。
- 删掉的场景在 `cut/`，永不真删，想捞随时捞。
- 选了 git 的作品：每天的稿子都有存档，说"回到某天/某版本"即可，无需懂 git。
