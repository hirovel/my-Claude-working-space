# 哲学（内部文档，写给自己）

这套体系的每个设计决策都从这几条信念推出。改任何 skill 之前先重读一遍。

## 信念

1. **为有梦想的人写作，不为批量生产。** 起点永远是"你想写什么"，不是榜单上什么有效。工具服务作者的故事。这是和 oh-story 一类量产流水线的根本分界：它们的第一性原理是市场验证（扫榜→拆文→模块组装→AI 代工），作者被降权为流水线操作员；我们的第一性原理是作者主权，AI 是尊重你写作方式的搭档。
2. **作者主权。** 发现式与大纲式同为一等公民，按情节·人物·世界观三维度自由定位；执笔可以是 AI 主笔、共笔或作者主笔，随时一句话切换。工具适应作者，不是作者适应流程。
3. **极简是长期主义。** 写进 skill 的每一行都在和模型的直觉抢方向盘。模型逐年变强：重型脚手架（几百行流程、打分表、题材公式）是在替今天的模型补短板，模型进化后就成了枷锁和债务；少而准的纪律和外置的记忆补的是模型**架构性的**短板（上下文有限、跨会话失忆），会随模型变强而增值。所以每一行都要答得出"这行防什么失误"，答不出就删。
4. **纪律不是流程。** skill 只防真实的失误——跨章失忆、设定漂移、承诺烂尾——不规定你怎么写、写什么。方差该消灭的是"该做的事没做"，不是"写出来的东西不一样"。
5. **正文是唯一事实源。** 圣经和账本是正文的索引，由收割自动维护。上下文窗口易失，文件持久。杂务全部静默自动，作者只管写。
6. **大师方法是营养，不是教条。** 任何方法论经由 /story-absorb 进入：精读→蒸馏→安置在最便宜的层级；题材模板、平台经验、成功学挡在门外；与既有纪律冲突的方法化为光谱上的一个位置，交给作者选。体系只在两种情况下生长：实测暴露新失误，或吸收管道带来真正新的 craft。

## 与 mattpocock/skills 的关系

只继承元层：双轨调用、状态外置、完成判据、锚点词、正向表述、剪枝（详见《matt-skills-精读笔记》）。craft 层全部来自写作大师（首个样本：桑德森，见 sources/）。matt skills 面世时市面上早有更"全面"的工程流水线，它赢在品味与哲学——小、可组合、纪律而非流程。本项目做小说领域的同一生态位。
