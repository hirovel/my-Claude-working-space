# 布兰登·桑德森 · BYU 318R 创意写作课

> 吸收管道的第一个样本。格式：核心方法 → 适用边界 → 蒸馏去向。

## 核心方法

- **发现式 vs 大纲式**：光谱而非二选一，可按情节/人物/世界观分别定位；桑德森本人是情节大纲式+人物发现式。两种方式各有系统性风险：发现式易写进死胡同、大修成本高；大纲式易写出"完成作业感"、人物僵硬。
- **承诺—推进—兑现**（Promise / Progress / Payoff）：故事对读者的契约。开篇基调、人物欲望、类型本身、伏笔都是承诺；推进必须可感知；兑现要"意料之外、情理之中"。
- **人物三滑尺**：好感度、主动性、能力——三个可独立调节的量；人物弧线=滑尺随故事移动。
- **世界观冰山**：展示 10%，暗示 90%，营造纵深错觉。**魔法定律**：限制比能力有趣；用魔法解决问题的能力与读者对它的理解成正比；先深挖已有设定再添新的。
- **情节框架是工具箱**：三幕、英雄旅程、尝试—失败循环（"是的，但是 / 不，而且"）按需取用，不是必填模板。
- **修订独立于初稿**；写作小组反馈原则"描述问题，不开药方"。
- 最重要的能力是**写完**。

## 适用边界

面向长篇类型小说（奇幻/科幻为主），对文学性短篇和实验写作的覆盖弱；"写完优先"预设了以出版/连载为目标的作者。
