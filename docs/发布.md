# 发布（内部文档）

## 两仓模型

- **工作仓库**（本仓库，私有）：skills + 全部内部文档（哲学、精读笔记、设计草案、决策记录、sources/ 精读笔记）。
- **公开仓库**（独立新建）：只有 `skills/`、`README.md`、`CONTEXT.md`、`LICENSE`。由 `scripts/publish.sh` 从工作仓库导出。

**为什么必须是独立新建的仓库**：本仓库的 git 历史里已经提交过内部文档，即使删除文件，任何人翻历史都能看到。所以公开版不能由本仓库改造或开源，只能是一个从零建立、只接收导出快照的新仓库。

## 发布步骤

1. 在 GitHub 新建公开仓库（如 `story-skills`），clone 到本地。
2. 在工作仓库运行 `scripts/publish.sh <公开仓库路径>`。
3. 到公开仓库 commit + push。以后每次发布重复 2–3。

## 公开/内部边界

| 公开 | 内部（永不导出） |
|---|---|
| skills/（以方法命名，不署人名） | docs/ 全部：哲学、精读笔记、设计草案、决策记录 |
| README（matt 风格门面） | docs/sources/（记录出处的精读笔记） |
| CONTEXT.md 术语表 | scripts/、评测工作区 |

首次发布前补一个 LICENSE（倾向 MIT，发布时再定）。
