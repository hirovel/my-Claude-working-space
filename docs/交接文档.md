# 交接文档（2026-08-19，供新 session 的 agent 与作者共同阅读）

## 这个项目是什么

一套中文小说写作 agent skills，目标是在小说创作领域达到 mattpocock/skills 在工程领域的地位：
**有品味、极简、作者主权**——辅助有想法的人写自己的故事，不做网文量产流水线。
仓库：`hirovel/my-Claude-working-space`，分支 `claude/story-writing-skills-system-pqdxur`，全部已推送。

## 一句话架构

```
主流程（手动）   /setup-story-skills（机械配置，一次）→ /brew（酝酿访谈，反复）⇄ /draft（起草，天天）
                /absorb（吸收新方法）· /ask-hiro（路标）
纪律（自动）     wrap（收工=收割→交接→存档）→ harvest（收割=正文→圣经/账本，冲突报告）
词汇层（自动）   promises（承诺·推进·兑现+账本格式）· characters（人物四栏档案格式）
```

9 个 skill 共约 280 行，全在 `skills/`。作品目录结构与术语见 `CONTEXT.md`（术语表是全体系共享语言）。

## 支撑整个设计的五个想法（新 agent 必须内化）

1. **双源**：从 mattpocock/skills 只继承**元层**（双轨调用、状态外置、完成判据、锚点词、正向表述、剪枝——精读笔记见 `docs/matt-skills-精读笔记.md`）；craft 层来自写作大师（首个：桑德森，`docs/sources/`），经 `/absorb` 管道进入，公开层以方法命名不署人名。
2. **两个空白生态位差异化**（四个竞品全都没有，见 `docs/同类项目教训.md`）：**承诺账本**（承诺开出→推进→兑现的跨章生命周期追踪）和**发现式写作一等公民**（三维度光谱，绝不逼作者先写大纲）。
3. **极简是长期主义**：重脚手架替今天的模型补短板、随模型进化变成债务；少而准的纪律+外置记忆补的是架构性短板（上下文有限、跨会话失忆），随模型变强而增值。每行要答得出"防什么失误"，答不出就删。哲学全文：`docs/哲学.md`。
4. **用户可知原则**：一切状态（账本/圣经/交接/档案）是作者可读可编辑的 markdown，AI 是记账员不是所有者，收割尊重作者手改。正文是唯一事实源，圣经账本只是索引。
5. **杂务全自动**：记账、归档、收件箱清理、git 存档静默完成；任何 skill 不得给作者发表单（评估疲劳教训）；作者的心智模型只需要"账本一屏、说收工就存档、随时能回到任何一天"。
