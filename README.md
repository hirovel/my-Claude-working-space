# Story Writing Skills

一套中文小说写作 skills：让 Claude 成为内化了写作纪律的创作搭档，而作者只管写小说。

参考 [mattpocock/skills](https://github.com/mattpocock/skills) 的体系架构原则（双轨调用、状态外置、为 agent 写文档的元规则），craft 层来自创意写作课程（布兰登·桑德森 BYU 318R：发现式/大纲式光谱、承诺—推进—兑现）。设计过程见 `docs/`。

## 设计原则

1. **一切为方便写小说**。流程感能省则省；限制加得越多，模型的文笔和创造力越受损，所以每个 skill 只保留真正防失误的最小纪律。
2. **发现式与大纲式都是一等公民**。按情节/人物/世界观三维度分别定位，发现式作者绝不被逼写大纲。
3. **杂务全自动**。记账、归档、收件箱清理、版本存档，agent 静默处理，不打扰写作。
4. **状态外置**。正文是唯一事实源；圣经、账本是它的索引；上下文窗口易失，文件持久。

## Skills（M1 最小骨架）

| skill | 触发 | 用途 |
|---|---|---|
| `/setup-story` | 手动 | 开新作品：访谈光谱定位、执笔模式、git/纯本地二选一，安装收割护栏 |
| `/story-develop` | 手动 | 发展想法：大纲式盘问 / 发现式攒碎片 |
| `/story-write` | 手动 | 写正文的日常主循环（执笔模式：AI 主笔/共笔/作者主笔，随时切换） |
| `story-harvest` | 自动 | 收割：正文 → 圣经/账本，冲突报告；护栏 hook 兜底 |
| `/story-help` | 手动 | 路标：不记得用哪个时问它 |

术语表见 `CONTEXT.md`。

## 安装

把 `skills/` 下的目录复制到 `~/.claude/skills/`（全局）或作品仓库的 `.claude/skills/`（单作品），或安装打包好的 `.skill` 文件。

## 路线

M1 骨架（当前）→ 实战写 2–3 章 → 用实际失灵点驱动增补（修订、交接强化、人物滑尺等），见 `docs/story-skills-设计草案.md`。
